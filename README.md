# 中国历史年代轴

一条轴读到底：从夏后氏立国（约前 2070）到 1949 年。同一段岁月里并存的政权横向并列成多条平行轨道，点开任一轨道看帝王、年号与大事记。

- 单文件自包含：`index.html`（HTML + CSS + JS 全部内联，无外部依赖，双击即开）
- 11 个时段 / 51 个政权 / 432 条大事
- 42 个政权附完整帝系表（帝号、姓名、在位年、全部年号），`#p=<政权id>` 页内路由
- 段内时间轴按各政权实际起止取齐，并行政权不强行对齐起点

打开方式：直接用浏览器打开 `index.html`；或在仓库 Settings → Pages 里把 `main` 分支根目录设为站点源。
